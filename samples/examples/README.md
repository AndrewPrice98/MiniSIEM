# Example logs

A library of self-contained log scenarios for trying MiniSIEM's parsers and detection rules.
Each file is one day on its own host, with its own users and IPs, so you can load one file or all of them together.

Generated by `scripts/generate_examples.py` (deterministic). Do not edit by hand.
Expected results live in `manifest.json` and are checked by `backend/tests/test_examples.py`.

```bash
cd backend
python -m minisiem examples        # reset the database and load every file below
python -m minisiem ingest ../samples/examples/auth-compromise-chain.log --source auth   # or one at a time
```

## Known detection gaps

| File | Source | Lines | Expected alerts | What it shows |
|---|---|---|---|---|
| `auth-distributed-bruteforce.log` | auth | 223 | none | **Distributed brute force (low and slow).** 80 different IPs each try root twice over 40 minutes. That is 160 failures, but no single IP reaches the threshold.<br>**Gap:** Per-IP thresholds miss botnet-style attacks. A per-target-user threshold or a global failure-rate rule would catch this. |
| `auth-sudo-denied.log` | auth | 82 | none | **Repeated sudo denials.** A user who is not in sudoers keeps trying, and another fails their password three times. The commands themselves are routine.<br>**Gap:** No rule watches sudo failures. Repeated 'NOT in sudoers' events are a useful privilege-escalation signal. |
| `access-slow-scan.log` | web | 742 | none | **Slow directory scan (rate-limited).** The same wordlist as the gobuster example, at one request every 8 seconds, so about 7 per minute against a threshold of 20.<br>**Gap:** Fixed short windows miss throttled scanners. A long-window rule (e.g. 100 404s in an hour) or a per-IP distinct-path count would catch this. |
| `access-login-bruteforce.log` | web | 614 | none | **Web login brute force.** One IP posts to /login 120 times in four minutes, getting 401 every time and a 302 at the end.<br>**Gap:** No rule covers web authentication. A threshold on POST /login with 401 per IP, followed by a 302, mirrors MSIEM-001 and MSIEM-002 for SSH. |
